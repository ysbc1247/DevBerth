# Claude Code Repository Instructions

Before starting or resuming work:

1. Read `AGENTS.md` when it exists and follow it as the repository's working agreement.
2. Read `docs/next-steps/README.md` when it exists and treat it as the canonical handoff for unfinished work.
3. Inspect the current branch, `HEAD`, Git status, recent commits, and active services before changing anything.
4. Preserve unrelated staged, unstaged, and untracked changes.
5. Verify handoff claims against the current repository and runtime state, then continue the listed next tasks in priority order.

When the user invokes the repository's `save` command, follow the complete handoff protocol in `AGENTS.md` and keep `docs/next-steps/README.md` current for the next Codex or Claude Code session.
